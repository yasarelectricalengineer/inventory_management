Import from Google Drive

  1. Google Drive has opened in a new tab (the folder you set in Settings). Find your backup file (inventory-backup-….json).
  2. Right-click it and choose Download.
  3. Come back to this tab and click Choose downloaded file below.
  4. Check the summary and confirm. All inventory data is restored from the file.

Importing replaces the data currently in this browser.
